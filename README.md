# 🍷 JUICE MALL — Pure Cold-Pressed & Artisanal Elixirs

> A production-quality, high-end, responsive frontend experience for an artisanal juice bar and cold-pressed lifestyle e-commerce brand. Built with **React**, **Vite**, **Tailwind CSS**, **GSAP ScrollTrigger**, **Framer Motion**, **Lenis Smooth Scrolling**, and **Outfit Font**.

---

## 🎨 Color Palette

The entire design system is styled around the **ColorHunt Palette [790d16e5d3aff5efe1aec4d4](https://colorhunt.co/palette/790d16e5d3aff5efe1aec4d4)**:

| Role | Hex | Visual Tone | Usage |
| :--- | :--- | :--- | :--- |
| **Primary Accent / Brand Core** | `#790D16` | Deep Crimson / Ruby Burgundy | Brand logo, primary buttons, badges, glowing accents, headlines |
| **Secondary Accent / Highlight** | `#E5D3AF` | Warm Almond Gold / Cream Sand | Card borders, subtle badges, bottle caps, secondary highlights |
| **Primary Light Background** | `#F5EFE1` | Warm Ivory Linen | Light mode canvas, card surfaces, modal background |
| **Cool Tint / Fresh Accent** | `#AEC4D4` | Frosted Mineral Sky / Slate Mist | Hydration elements, subheadings, subtle borders, tags |
| **Dark Mode Surfaces** | `#13090B` / `#1C0F12` | Deep Charcoal Infused with Ruby | Dark mode background, glassmorphic cards, deep borders |

## ✨ Features

- 🌿 **100% Responsive & Portfolio-Grade Design**: Modern editorial layout inspired by premium D2C lifestyle brands (Apple, Erewhon, Liquid Death, Daily Harvest).
- ⚡ **GSAP + Lenis Smooth Scrolling**: Fully synchronized inertia smooth scroll with `ScrollTrigger` animations, ticker integration, and memory leak prevention.
- 🎨 **Adaptive Light & Dark Mode**: Tailored warm ivory linen (`#F5EFE1`) & deep charcoal surfaces (`#13090B`) with persistent `localStorage` and system theme detection.
- 🍷 **Hero Showcase**: Staggered typography reveals (*"FRESHNESS YOU CAN TASTE & FEEL"*), floating superfood accents, cursor-based parallax on desktop, and custom SVG layered bottle visualization.
- 🏷️ **Dynamic Flavor & Menu Filtering**: Filter by category (Ruby Elixirs, Almond & Gold, Frost Mist, Ivory Detox, Velvet Silk, Protein Luxe, Hydra Glaze) and live search with smooth `AnimatePresence` layout transitions.
- 🧪 **Interactive "Build Your Own Juice" Lab**: Multi-step live juice mixologist app (Base + Superfoods + Boosters + Size) with real-time price calculation, animated liquid fill glass graphic, and custom blend checkout.
- 🌟 **Featured Juice Spotlight**: Deep-dive feature section for *Crimson Velvet Nectar* with superfood tags, nitric flow indicators, and nutritional integrity pills.
- 🎁 **Special Offers & Cleanse Packs**: Asymmetrical editorial bundle cards with discount tags, included juices breakdown, and one-click add to bag.
- 🛒 **Full Shopping Bag & Express Checkout**: Slide-over cart drawer, promo code discounts (`FRESH20`, `VIP50`), quantity stepper, free express shipping thresholds, and confetti order confirmation.
- 🔍 **Quick View Nutritional Modal**: Comprehensive ingredient list, macros (Sugars, Protein, Hydration), calorie counter, and direct add to bag.
- 💬 **Customer Testimonials & Social Gallery**: Verified buyer reviews with star ratings and interactive Instagram lifestyle masonry grid.
- 📬 **Validated Sommelier Contact Form**: Interactive inquiry form with focus states, field validation, and confirmation state.

## 🚀 Getting Started

### 1. Installation
```bash
# Navigate into the project folder
cd "juice mall"

# Install dependencies
npm install
```

### 2. Running Locally
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 3. Creating a Production Build
```bash
npm run build
```
